# Milestone 3: Business X-Ray + CEO Dashboard + Management Action Center

Status: **backend and agent flows delivered 2026-11-09; client UI in progress** (M2 delivered 2026-11-09). Semantic search (M3-11) deferred to M5, see ADR-019. Goal: the spec 11 demo flow end to end on synthetic data: consultant creates client → CEO answers 5 intake questions → system shows departments and discovers 4 applications → Finance and Operations ask 2 follow-up questions each → an agent delivers an evidence-based pain point and a proposed workflow → CEO approves an action → task owner receives it → a scheduled check verifies the outcome → the CEO dashboard reflects the change with source, timestamp and status.

## Scope

In: migration 0006 (`processes`, `process_steps`, `pain_points`, `findings`, `opportunities`, `kpis`, `kpi_observations`, `dashboards`, `dashboard_widgets`, `tasks` (management action center), `briefings`, `connections`, `credentials_metadata`); KPI Registry with "no KPI without source and formula"; `DashboardSpecification` rendered by a widget whitelist (shadcn chart on Recharts, `accessibilityLayer`); CEO Intelligence agent producing `KpiDefinition`s, `DashboardSpecification` and the daily `ExecutiveBriefing` with exactly the eight sections; Finance and Operations agents (question rounds + `Finding`s with claim type); Process Redesign agent producing an `Opportunity` with business case and TO-BE steps; Management Action Center (issue → action → owner → approval → task → verification → closure); Business X-Ray report page; client onboarding wizard (consultant creates tenant, invites CEO, 5 intake questions); pgvector embeddings and semantic search over vault facts and documents (Docker Postgres becomes the default dev database); CopilotKit spike for the Interview Inbox.

Out: real connectors (M5), Agency Vault (M4).

## Acceptance (spec 11)

Tenant A never sees tenant B records; a missing KPI source is never filled with invented amounts; every suggestion shows source status and uncertainty; a risky mutation is blocked without approval; a failed scheduled run shows as an incident; the CEO can view, approve, delegate and later see what happened; the Design Agent only uses render-safe specs; all versions, costs, reviews and decisions are traceable.
