# Milestone 2: Client Workspace + Knowledge Vault

Status: **delivered 2026-11-09** (semantic search deferred to M3 as planned). Status per ticket at the end of this document. Goal: a client user answers a discovery question; the answer becomes a provisional fact with a source; an agent detects a contradiction and asks for verification; a reviewer promotes the fact to verified; another agent retrieves the fact with its source; revisions can be reverted; forbidden documents cannot be found through search.

## Scope

In: answers, evidence, facts with verification lifecycle, contradiction detection, fact verification requests, vault documents with revisions and revert, backlinks, full-text search with RLS, retrieval audit, Interview Inbox answer flow, Vault browser and editor (Markdown with frontmatter), Obsidian-compatible import/export of a tenant vault (zip of Markdown files), tenant policy for agent write mode (draft vs proposal). Discovery agent round 2 consumes answers and facts.

Out: embeddings and semantic search (pgvector, M3 when Docker Postgres is the dev default), Agency Vault (M4), real connectors (M5).
