# Milestone 1: Mission Control core + first agent flow

Goal: the operator can manage agents for two synthetic tenants and one real agent flow runs end to end, autonomously on the backend worker, with a trace, a source and an approval. The Autonomy Acceptance Test (`docs/agent-runtime.md` §9) must pass with Claude Code closed. This is the first milestone submitted for approval; M0 (foundation) is the scaffold delivered alongside this document.

## Scope

In: tenancy-aware auth, agent definitions and instances, tasks, runs, run events, approvals, schedules, incidents, budgets; pg-boss worker; one Discovery & Interview agent producing `QuestionRequest`s from a synthetic company profile through Mastra; Mission Control pages: Overview, Client Workspaces, Agent Detail, Tasks, Runs & Traces, Approvals, Schedules, Errors & Incidents, Costs (read-only numbers from run events).

Out: Knowledge Vault UI (M2), dashboards and KPIs (M3), Agency Vault (M4), real connectors (M5), CopilotKit chat (M3).

## Acceptance (Mission Control MVP, spec 4F)

1. Operator distinguishes two test clients and sees working and waiting agents per client.
2. Operator inspects one task with result and source.
3. Operator sends feedback, reschedules a run, sees a detected error as an incident, and handles an approval.
4. Tenant A sees nothing of tenant B via UI, API, run logs or metadata (automated tests + manual check).
5. No claim of 24/7 agents: every run shows its trigger (schedule, event, command).
6. Autonomy Acceptance Test passes: a scheduled run executes, writes to the correct vault and appears in Mission Control while Claude Code is closed; a failed run becomes an incident; a worker restart resumes the run.

## Simulated versus real in M1

- Real: database, RLS, worker, state machines, approvals, audit, Mastra run with Anthropic model when `ANTHROPIC_API_KEY` is set.
- Simulated: without an API key the runtime uses a deterministic `SimulatedModel` that returns fixture questions, clearly labelled `simulated: true` in run events and UI.
- Not connected: any client system.
