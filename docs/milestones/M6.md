# Milestone 6: Hardening + Technology Intelligence + pilot

Status: **in progress** (started 2026-11-10). Technology Intelligence Center backend, data retention, the security evaluation suite with agent boundary hardening and the review and go-live checklists are delivered; Mission Control UI in progress; the pilot go-live itself needs Railway access, an API key and the M5 owner decisions.

## Scope

In: Technology Intelligence Center (spec 4D): approved sources, scheduled detection, `tech_updates` carrying the UpgradeProposal fields, lifecycle detected -> assessed -> approved -> applied (or rejected, rolled_back) with the artefact rule per kind (code update needs a pull request, skill update a new immutable SKILL.md version, knowledge update a published agency record), test result before applying, rollback that restores the stable skill channel; data retention with platform defaults, tenant overrides and floors, weekly sweep in agency scope only, deletion requests decided by an agency reviewer and executed by the worker (document and connection data automated; subject data and tenant off-boarding by runbook with a written summary); security evaluation suite (prompt injection in answers and documents, wrong tenant scope, expired credentials, agent trying to change phases or approve); fix of the notification delivery defect found during M6; external review checklist for RLS and secrets handling; pilot go-live checklist (needs the M5 owner decisions and Railway access).

Out: automatic production upgrades of any kind (refused by design), Agency Knowledge Curator Agent (optional), semantic search (ADR-019).
