# Agent Registry (definitions)

Each agent definition is an agency template. A tenant activates only what it needs. Fields below mirror `agent_definitions` and the SKILL.md frontmatter (ADR-007). Authority levels follow autonomy tiers: **T1** read/classify/draft autonomously and log; **T2** act on low-risk reversible items and notify; **T3** propose and wait for approval. No agent has authority over payments, bank data, HR decisions, legal commitments or contract confirmations.

Cost budget: each instance has a monthly token/USD cap and a per-run cap; defaults set at activation and visible in Mission Control → Costs.

Input/output contracts per agent are listed in `packages/contracts/README.md` once that package lands (`QuestionRequest`, `Finding`, `Opportunity`, `KpiDefinition`, `DashboardSpecification`, `ExecutiveBriefing`, `UpgradeProposal`, `AgentRunResult`, etc.). Every output carries `tenant_id`, `source_ids`, `confidence`, `generated_at`, `review_status`, `permissions_context`.
